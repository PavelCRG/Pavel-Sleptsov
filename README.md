# Sleptsov Pavel — Web Development

Материалы по курсу «Средства создания приложений».

## Структура репозитория

```
Pavel-Sleptsov/
├── README.md
├── LAB/
├── LECTION/
├── CONTROL/
├── PRACTICE/
├── WEB_ALL/
└── WEB_PRACTICE/
```

## Описание

- **LAB** — лабораторные работы. 
- **LECTION** — лекции: PDF и примеры с занятий.
- **CONTROL** — контрольные задания (выполненные работы).
- **PRACTICE** — практические работы по курсу.
- **WEB_ALL** — сайт-портал по курсу. 
- **WEB_PRACTICE** — отдельный сайт WEB-практики.
