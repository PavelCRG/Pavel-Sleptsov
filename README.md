# Sleptsov Pavel — Web Development

Учебные материалы 3 и 4 курса. Сайт лежит отдельно в `WEB_ALL`.

## Структура репозитория

```
Pavel-Sleptsov/
├── COURSE_3/
│   ├── LAB/
│   ├── LECTION/
│   ├── CONTROL/
│   ├── PRACTICE/
│   └── WEB_PRACTICE/
├── COURSE_4/
│   └── JS_PHP_NODE/
│       ├── LECTION/   
│       ├── LAB/       
│       └── OKR/
├── WEB_ALL/
└── README.md
```

## Описание

- **COURSE_3** — то, что уже было: лабораторные, лекции, контроль, практика и WEB-практика.
- **COURSE_4** — предмет JS · PHP · Node. 
- **WEB_ALL** — сайт-портал. На первой странице выбор: 3 курс или 4 курс.
