# Sleptsov Pavel — Web Development

Материалы по курсу «Средства создания приложений».

## Структура репозитория

```
Pavel-Sleptsov/
├── README.md
├── LAB/
├── LECTION/
├── CONTROL/
├── WEB_ALL/
└── WEB_PRACTICE/
```

## Описание

- **LAB** — лабораторные работы. Структура как на [GitHub](https://github.com/PavelCRG/Pavel-Sleptsov/tree/main/LAB): ранние лабы — HTML в корне папки; лаб. 13–14 — `Условие/`, `Примеры/`, `Индивидуальное/`; 17–32 — заготовки под страницы учебника.
- **LECTION** — лекции: PDF и примеры с занятий.
- **CONTROL** — контрольные задания (выполненные работы).
- **WEB_ALL** — сайт-портал по курсу (приветствие, разделы, просмотр внутри страницы).
- **WEB_PRACTICE** — отдельный сайт WEB-практики (занятия по дням).
