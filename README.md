# Sleptsov Pavel — Web Development

Материалы по курсу «Средства создания приложений».

## Структура репозитория

```
Pavel-Sleptsov/
├── README.md
├── LAB/
├── LECTION/
├── CONTROL/
├── WEB_ALL/
└── WEB_PRACTICE/
```

## Описание

- **LAB** — лабораторные работы: HTML, CSS, JavaScript. Папки по номерам работ, исходные файлы заданий.
- **LECTION** — лекции: разметка, формы, таблицы, CSS и примеры с занятий.
- **CONTROL** — контрольные задания.
- **WEB_ALL** — единый сайт-портал по курсу (приветствие, разделы, просмотр работ внутри страницы).
- **WEB_PRACTICE** — сайт по WEB-практике (занятия по дням, задания и готовые страницы).

## Технологии

- HTML
- CSS
- JavaScript
