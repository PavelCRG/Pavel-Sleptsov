Задание 2a

Создайте блок объявлений для селектора тега абзац и примените его к тексту из задания 1

Родственные селекторы — это селекторы в CSS, которые позволяют выбирать элементы на основе их взаимного расположения в HTML-документе. Они используются для стилизации элементов, находящихся в определённой связи с другими элементами.

Основные виды родственных селекторов:
1. Соседний селектор (A + B) — выбирает элемент B, который непосредственно следует за элементом A.
2. Родственный селектор (A ~ B) — выбирает все элементы B, которые находятся после элемента A на том же уровне вложенности.
3. Дочерний селектор (A > B) — выбирает элементы B, которые являются прямыми потомками элемента A.
4. Контекстный селектор (A B) — выбирает все элементы B, которые находятся внутри элемента A на любом уровне вложенности.
