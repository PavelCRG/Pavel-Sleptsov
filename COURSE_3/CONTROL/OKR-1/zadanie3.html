Задание 3d

Отформатируйте текст, используя универсальный селектор

Родственные селекторы — это селекторы в CSS, которые позволяют выбирать элементы на основе их взаимного расположения в HTML-документе. Они используются для стилизации элементов, находящихся в определённой связи с другими элементами.

Основные виды родственных селекторов: соседний селектор (A + B), родственный селектор (A ~ B), дочерний селектор (A > B) и контекстный селектор (A B).

Задание 3e

В отдельном абзаце запишите основные отличия селекторов класса (.class) и идентификатора (#id). Примените цвет идентификатора к этому абзацу.

Основные отличия селекторов класса (.class) и идентификатора (#id):
1. Уникальность: Идентификатор (#id) должен быть уникальным на странице и использоваться только один раз. Класс (.class) можно использовать многократно на разных элементах.
2. Приоритет (специфичность): Идентификатор имеет более высокий приоритет (значение 100), чем класс (значение 10).
3. Синтаксис: В CSS класс обозначается точкой (.myclass), идентификатор - решеткой (#myid). В HTML класс указывается через атрибут class="...", идентификатор - через атрибут id="...".
4. Назначение: Классы предназначены для стилизации групп элементов, идентификаторы - для идентификации конкретного элемента (например, для якорей или JavaScript).
