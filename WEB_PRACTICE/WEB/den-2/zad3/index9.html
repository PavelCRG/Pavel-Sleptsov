Реклама

Voxiva

Voice-first платформа для работы

Voxiva — экосистема, где голос, задачи, текст и автоматизация связаны в одном потоке. Вы говорите намерение — система помогает оформить задачи, черновики и следующие шаги, не разрывая контекст между приложениями.

Сейчас (Windows, бета):
Voxiva Voice — диктовка в любое поле (IDE, терминал, браузер), локальное распознавание речи, горячая клавиша.
Voxiva Space — рабочее пространство: доска задач, voice inbox, терминалы PowerShell и сессии с агентами в одном окне.

В разработке: Voxiva MCP (общий контекст для Cursor, Claude, Codex), Voxiva CLI (команды из терминала по намерению). Поддержка 99+ языков и полный облачный режим — в roadmap.
