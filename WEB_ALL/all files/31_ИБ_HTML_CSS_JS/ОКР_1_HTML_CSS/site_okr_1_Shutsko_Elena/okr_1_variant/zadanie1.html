Ссылка (гиперссылка) — это элемент веб-страницы, который позволяет пользователю перейти от одного документа к другому или к определенному разделу внутри одной страницы. Ссылки являются основой навигации во всемирной паутине (WWW) и обычно выделяются цветом или подчеркиванием, меняя вид курсора при наведении.
