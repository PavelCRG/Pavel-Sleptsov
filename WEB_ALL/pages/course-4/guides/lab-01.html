Инструкция

Лаб 01 — полная инструкция

Открывай файлы из списка лабораторной по очереди. Ниже — что нажимать и что писать в каждом.

3_05.html — модальные окна

На странице три кнопки: alert, confirm, prompt.

  1. Нажми alert — появится окошко «Сообщение для вас». Жми OK.
  2. Нажми confirm — вопрос про закрытие окна. OK попытается закрыть вкладку, Отмена — оставит как есть.
  3. Нажми prompt — попросит имя. Введи, например, Павел и OK. Имя уйдёт в строку статуса окна (внизу браузера, если она включена).

3_06.html — новое окно

Поля ввода нет.

  1. Нажми Открыть новое окно.
  2. Должно открыться маленькое окно с тем же 3_05.html. Если браузер блокирует всплывающие окна — разреши для сайта.

3_07.html — открыть и изменить размер

Две кнопки: Открыть и Изменить. Обе задают вопросы через prompt.

  1. Нажми Открыть. В первом окошке адрес — оставь 3_05.html (или впиши другой html из этой папки) и OK.
  2. Второе окошко спросит, перенести ли фокус на новое окно: OK — да, Отмена — окно уйдёт на задний план.
  3. Нажми Изменить. Первое число — ширина, по умолчанию 200. Второе — высота, по умолчанию -100 (минус уменьшает).
  4. Можно оставить как есть и жать OK-OK, либо поставить свои числа, например 300 и 150.

3_08.html — таймер

Сверху счётчик, снизу кнопка Stop.

  1. Открой файл — счётчик сам начнёт тикать каждую секунду.
  2. Нажми Stop — счётчик остановится. Больше ничего вводить не нужно.
