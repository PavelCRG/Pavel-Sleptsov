Инструкция

Лекции 07–09 — полная инструкция

Самое важное: куда писать и какую кнопку жать. Рабочее поле почти везде — нижнее (второе). Верхнее часто не используется.

pos35.html — дата (кнопки сами пишут)

Одно поле. Вводить ничего не нужно — только кнопки.

  1. Нажми розовую Первая — в поле текущая дата и время.
  2. Нажми голубую Вторая — timestamp (длинное число).
  3. Нажми зелёную Третья — фиксированная дата 7 октября 2013, 11:23:34.

pos36.html — часы

  1. Первая — текущий час (локальный).
  2. Вторая — час по UTC.
  3. Третья — дата с часом, выставленным на 23.

pos37.html — сдвиг даты на N дней

  1. Нажми Первая — в поле текущая дата (можно и сразу вписать число дней).
  2. Сотри и впиши число дней, например 5.
  3. Нажми Третья — дата сдвинется на 5 дней вперёд.
  4. Вторая просто очищает поле.

pos38.html — разница между двумя датами

Три поля: дата 1, дата 2, результат. Формат: день месяц год через пробел.

  1. В первое поле: 7 10 2013 (7 октября 2013).
  2. Во второе поле: 15 10 2013.
  3. Нажми Вычислить — в третьем поле число дней между датами (здесь 8).
  4. Очистить — трёт все три поля.

pos39.html / pos40.html — часы

  1. Открыл — часы сами тикают. Кнопок нет, ничего вводить не нужно.
  2. pos40 — графические часы с картинками; просто посмотри, как идут стрелки/точки.

pos41.html — cookie

Работает нижнее поле (pp1). Формат записи: имя;значение;дней

  1. Впиши во второе (нижнее) поле: user;Pavel;7.
  2. Нажми Вторая — cookie записалась, поле очистится.
  3. Впиши только ключ: user.
  4. Нажми Третья — в поле появится что-то вроде user=Pavel.
  5. Первая очищает поле ввода.

pos42.html — LocalStorage (3 кнопки)

Пиши во второе (нижнее) поле. Формат: ключ=значение

  1. Впиши name=Pavel.
  2. Нажми голубую Вторая — записалось в LocalStorage, поле очистится.
  3. Впиши только name.
  4. Нажми зелёную Третья — увидишь name=Pavel.
  5. Розовая Первая — очистить поле.

zad42_1-2.html — LocalStorage (6 кнопок)

То же нижнее поле. Это главный тренажёр блока.

  1. Запись: впиши name=Pavel → кнопка Вторая.
  2. Чтение: впиши name → Третья → получишь name=Pavel.
  3. Удалить один ключ: впиши name → Четвертая → текст «Запись 'name' удалена».
  4. Сумма чисел: сначала запиши mm=2,3,-1,11,-4 кнопкой Вторая.
  5. Потом впиши mm и нажми Шестая (Сумма) → получишь строку с суммой (здесь 11).
  6. Пятая — полная очистка LocalStorage. После неё старые ключи пропадут.
  7. Первая — просто очистить поле на экране.

zad41_1-2.hta — cookie в Windows

Открывай двойным кликом в проводнике, не через сайт.

  1. Запись cookie: во второе поле user;Pavel;7 → Вторая.
  2. Чтение: user → Третья.
  3. Удалить cookie: user → Четвертая.
  4. Пятая — показать все cookie в alert.
  5. Первая — очистить поле.
