Лабораторная 04 — визуальные эффекты

По материалам: 21_Визуальные_эффекты.pdf

Что сделал

Эффекты с картинками: удаление/приближение, пульсация, слайдер со сменой кадров, перетаскивание флагов.

Цель: рассмотреть сценарии с объектами, связанными с тегами HTML; создать анимационные изображения.

Объекты и изображения

  1. Многие объекты JS соответствуют HTML-тегам и входят в иерархию с корнем window.
  2. Коллекция document.images — все картинки на странице: document.images[0], images[1]…
  3. Доступ по имени: тег <img name="…"> → обращение через имя.
  4. Для анимации меняют height / width или src по таймеру setTimeout.

1.1 Удаление, приближение, пульсация

  1. Удаление: уменьшаем height на каждом шаге таймера, пока не достигнем предела.
  2. Приближение: наоборот — увеличиваем размер.
  3. Пульсация: чередуем увеличение и уменьшение (например, для serde4ko.gif).
  4. Запуск часто вешают на onMouseOver.

1.2 Чередование с предзагрузкой

  1. Создаём массив: imgslide = new Array().
  2. Каждый элемент — new Image(), задаём .src заранее.
  3. На таймере подставляем в document.images[0].src уже загруженный адрес — смена кадров без рывков.

Дополнительно

  • Слайдер и drag-and-drop флагов — те же идеи: таймер / события мыши + смена позиции или src.
  • Самостоятельная работа: свой эффект на базе height/src и setTimeout.
