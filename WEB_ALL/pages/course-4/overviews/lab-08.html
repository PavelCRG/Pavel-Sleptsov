Лабораторная 08 — регулярные выражения

По материалам: 25_lab_reguljar_repeet.pdf

Что сделал

14 примеров regexp + свой тест (один ответ, несколько, select, email по шаблону, соответствие).

Цель: изучить флаги и спецсимволы шаблона; уметь проверять ввод пользователя регулярными выражениями.

Темы из пособия

  • Флаги регулярного выражения [1, 344]
  • Специальные символы в шаблоне [1, 346–347]
  • Методы test(), exec() объекта RegExp и match(), replace(), search() объекта String [1, 344–345]

Теория по пунктам

  1. Регулярное выражение — шаблон для поиска и проверки строк. Создание: литерал /шаблон/флаги или new RegExp(…).
  2. Флаги: g — все совпадения, i — без учёта регистра, m — многострочный режим (^ и $ на каждую строку).
  3. RegExp.test(str) — true/false; exec(str) — найденное совпадение или null.
  4. У строки: match, replace, search — работа с тем же шаблоном.
  5. Частые символы: \d цифра, \w буква/цифра/_, ^ начало, $ конец, + / * / {'{'}n{'}'} — количество.
  6. Из PDF разобрать шаблоны email и телефона; для строки с числами — шаблоны /\d\d\d/m, /^\d\d/m, /\d\d$/m.
  7. Индивидуальное: тест с разными типами вопросов + отметка функцией; доп. — соответствие через drag-and-drop.

1.html — prompt

  1. В prompt укажи тег для поиска (по умолчанию можно h1) → OK.

2.html–13.html

  1. Открывай по порядку. Большинство примеров сами показывают результат или ждут клика.

ind.html — тест (правильные ответы)

  1. Q1: выбери g (найти все совпадения).
  2. Q2: отметь test() и exec() (не match — это метод String).
  3. Q3: в select — «цифра».
  4. Q4: email вида user@mail.ru.
  5. Q5: \d → цифра, \w → буква.
  6. Нажми Проверить — увидишь баллы и отметку.

test.html — ещё один тест

  1. Заполни ответы как в задании (software, соответствие категорий ПО, интерфейс, прикладные программы, текстовый процессор).
  2. Нажми РЕЗУЛЬТАТ — внизу появится число баллов.
