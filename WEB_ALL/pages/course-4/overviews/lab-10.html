Лабораторная 10 — перетаскивание объектов

По материалам: lab_27_перетаскивание_объектов.pdf

Что сделал

Сделал примеры и задания по Drag and Drop: pos28–pos30, zad29, zad30.

Цель: научиться связывать объект с событием и составлять скрипты перетаскивания объектов по окну браузера с использованием DOM.

Теория по пунктам

  1. Перетаскивание (drag-and-drop) — объект следует за курсором при зажатой кнопке мыши.
  2. Обычно вешают обработчики: onmousedown (старт), onmousemove (движение), onmouseup (отпускание).
  3. Позицию задают через CSS: position: absolute и свойства style.left / style.top (или transform).
  4. Координаты берут из объекта события: clientX, clientY (с учётом смещения курсора внутри элемента).
  5. Важно снимать движение при mouseup (и иногда при уходе курсора за пределы окна), иначе объект «залипнет».
  6. Практика: pos28.html–pos30.html, задания zad29_1, zad29_2, zad30_1.

pos28.html–pos30.html

  1. Открой файл — зажми объект мышью и перетащи по странице.
  2. Отпусти кнопку — объект должен остаться на новом месте.

zad29_1.html, zad29_2.html, zad30_1.html

  1. Выполни задание из условия: перетащи нужные объекты (есть картинки banana/lemon).
