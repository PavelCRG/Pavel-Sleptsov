Лабораторная 03 — доступ к HTML-элементам

По материалам: 20_lab_dostup_HTML_element.pdf

Что сделал

Универсальные свойства узлов, поиск по id/классу/тегу, innerHTML, смена цвета при наведении и изменение стилей элемента.

Цель: изучить универсальные методы и свойства объектов и уметь использовать иерархию для доступа к содержимому и свойствам HTML-элементов.

Темы из пособия

  • Универсальные свойства объектов [1, 316–317]
  • Универсальные методы объектов [1, 317–319]
  • Свойства элементов для работы с содержимым и стилями [1, 320]

Теория по пунктам

  1. У каждого узла есть связи с соседями: parent, childNodes, firstChild, nextSibling и т.п. — по ним ходят по дереву.
  2. Поиск в дереве:
    • document.getElementById(id)
    • document.getElementsByClassName(класс)
    • document.getElementsByTagName(тег)
  3. innerHTML — прочитать или заменить HTML внутри элемента.
  4. Стили через element.style: backgroundColor, left, top, width, height, fontSize.
  5. Пример из PDF: смена цвета фона при onmouseover / onmouseout.
  6. Задание: скрипт управления содержимым через innerHTML; скрипт изменения положения/размера/шрифта.
